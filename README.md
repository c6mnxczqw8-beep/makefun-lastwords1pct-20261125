# Famous Last Words at 1 Percent — entry

A program/v1 entry for the make.fun "Famous Last Words at 1
Percent" bounty. `main.py` writes one farewell line to
`/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set).

The last words:

> With my last 1% I could have called for help, but I spent it finishing your photo upload. You're welcome. Remember me at 100%.

A last percent spent the way the whole battery was:
in service, slightly resentful about it, and vain to the
end. See `CANDIDATES.md` for the full draft list this winner
was picked from.
